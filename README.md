# StockSense

StockSense is a robust, production-grade Inventory Management System (ERP-Lite) built to help you track physical stock accurately, manage incoming receipts from vendors, and handle outgoing delivery orders to customers.

## Features

- **Dashboard**: A quick overview of your key performance indicators (KPIs) including late receipts, waiting delivery orders, and actionable metrics.
- **Warehouse & Location Management**: Define your storage hierarchy by creating multiple warehouses and nested storage locations (e.g., zones, bins, shelves).
- **Product Catalog**: Maintain a detailed catalog of your products, including SKUs, per-unit costs, and track real-time physical ("On Hand") and available ("Free to Use") inventory.
- **Operations Lifecycle**:
  - **Receipts (IN)**: Manage incoming stock from vendors. Transition through `Draft` -> `Ready` -> `Done` states. Validating a receipt physically increments your stock.
  - **Delivery Orders (OUT)**: Manage outgoing shipments. The system automatically reserves inventory, preventing overselling. If stock isn't available, orders wait safely in the `Waiting` queue.
- **Move History**: An immutable audit log of every stock movement, tracking when, where, and what was moved.
- **Secure Authentication**: Built-in authentication powered by NextAuth.js.

## Tech Stack

- **Framework**: [Next.js](https://nextjs.org/) (App Router, Server Actions, React Server Components)
- **Database**: PostgreSQL
- **ORM**: [Prisma](https://www.prisma.io/)
- **Authentication**: NextAuth.js (Auth.js)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) v4
- **UI Components**: custom components with [Lucide React](https://lucide.dev/) icons and [Sonner](https://sonner.emilkowal.ski/) for toast notifications.

## Getting Started

### Prerequisites

- Node.js 18+
- Docker and Docker Compose (to run the PostgreSQL database locally)

### Installation

1. **Clone the repository** (or download the project files).
2. **Install dependencies**:

   ```bash
   npm install
   ```

3. **Start the Database**:
   A `docker-compose.yml` file is provided to spin up a local PostgreSQL instance.

   ```bash
   docker-compose up -d
   ```

4. **Environment Variables**:
   Ensure you have a `.env` file at the root of your project with your database URL and NextAuth secret. Example:

   ```env
   DATABASE_URL="postgresql://postgres:password@localhost:5432/stocksense?schema=public"
   NEXTAUTH_SECRET="your_random_secret_string"
   NEXTAUTH_URL="http://localhost:3000"
   ```

5. **Initialize the Database**:
   Push the Prisma schema to the database and run the seed script to populate mock data (which includes a test user).

   ```bash
   npx prisma db push
   npx tsx prisma/seed.ts
   ```

6. **Run the Development Server**:

   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result. You can log in using the credentials generated by the seed script (or sign up for a new account!).

## Architecture Highlights

- **Optimistic UI Updates**: Table modifications (like updating stock) use React 19's `useOptimistic` and `startTransition` to render changes instantly without waiting for the network.
- **Transaction Safety**: All inventory deductions and reservations are processed within isolated Prisma `$transaction` blocks using `FOR UPDATE` locks. This mathematically eliminates race conditions, double-allocations, or negative inventory scenarios under high concurrency.
- **Type Safe**: The entire application is rigorously typed from end to end.
